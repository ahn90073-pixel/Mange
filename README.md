# تطبيق إدارة Mange

واجهة React وVite عربية لإدارة المنصة، متصلة بـBackend الإدارة المستقل على Cloudflare Workers.

## فتح التطبيق

يفتح التطبيق مباشرة على لوحة الإدارة **دون حساب أو شاشة تسجيل دخول أو إنشاء حساب**. تُحمّل بيانات التاجر والمنتجات والسدادات من API العامة، وتُرسل إليها إجراءات الاعتماد والتعديل مباشرة.

> **تنبيه مهم:** اختير جعل لوحة الإدارة وAPI عامة. أي شخص يصل إلى Worker يمكنه قراءة بيانات التجار والطلبات والعملاء والسدادات وسجل التدقيق، كما يمكنه اعتماد/رفض المنتجات وتعديل الحالات والعمولات وإنشاء/إلغاء سجلات السداد. خانة العميل قد تعرض الاسم أو البريد الإلكتروني أو الهاتف؛ وسجل التدقيق يعرض عنوان IP وبعض تفاصيل العمليات. CORS ليس حماية من أدوات HTTP أو الاستدعاء المباشر. لا تستخدم هذا الإعداد إذا كانت البيانات غير مخصصة للنشر العام.

## تشغيل محلي

```bash
npm ci
cp .env.example .env.local
npm run dev
```

الإعدادات في `.env.local` تخص عنوان API والعملة فقط؛ لا تضع فيها أسرار قاعدة البيانات أو رموز دخول:

```env
VITE_ADMIN_API_BASE_URL=https://mangerbackend.ahn90073.workers.dev/api/admin
VITE_CURRENCY=EGP
```

عنوان API الافتراضي والعملة `EGP` مضمّنان في التطبيق.

## البيانات والعمليات المتصلة

تُحمّل لوحة المؤشرات والتجار والمنتجات والسدادات من API مع pagination. تشمل العمليات المرسلة للخادم اعتماد المنتج أو رفضه، الإبقاء على منتج منشور أو أرشفته، تحديث حالة التاجر ونوع العمولة، وإنشاء سند سداد. الخادم يحسب العمولة والرصيد ويتحقق من حد السداد.

## النطاقات وCORS

يسمح Worker حاليًا بـ`localhost:5173` و`localhost:4173` وأصل Android الافتراضي `https://localhost` وأصول Capacitor الأخرى. عند استضافة الواجهة على نطاق ويب مختلف، أضف الأصل المحدد إلى `ADMIN_CORS_ORIGINS` في مستودع `mangerbackend`. هذه القائمة تتحكم بترويسات المتصفح فقط ولا تمنع الوصول العام إلى API.

## Android OTA

نشر تغيير إلى `main` يشغّل GitHub Actions لإنشاء/تحديث حزمة الواجهة `ota-latest`. تطبيق Android يفحص التحديث وينزله؛ تُطبق الحزمة بعد إعادة فتح التطبيق. هذا لا ينشئ APK جديدًا.
